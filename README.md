## 🧭 How to Solve Questions

1. 👀 Understand problem
2. 🐢 Write brute force
3. ⏱️ Check time/space
4. ⚡ Optimize
5. ✅ Test edge cases

---

## 🎮 Mini Strategy

- Start with `practice1` ➜ move step by step
- Solve daily (2-4 questions) 🔥
- Re-solve old questions after 1 week ♻️
- Focus on patterns, not memorizing code 🧠
